# Security Policy

## Supported versions

Security fixes are provided for the latest released ShogiArena version.
Older versions may be asked to upgrade before a report is investigated.

## Reporting a vulnerability

脆弱性、credential、未公開の exploit を public Issue へ投稿しないでください。
GitHub の [Report a vulnerability](https://github.com/nyoki-mtl/ShogiArena/security/advisories/new) から、private vulnerability report として送信してください。

報告には、次の情報を含めてください。

- 影響を受ける ShogiArena のバージョンと実行環境
- 再現に必要な最小手順
- 想定される影響
- 既知の回避策

受領後は private report 上で調査状況を共有します。
修正版の公開前に、脆弱性の詳細を公開しないでください。
