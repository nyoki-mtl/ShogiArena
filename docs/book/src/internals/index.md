# 統計的検定とチューニングの内部技術

ShogiArena で使われている統計手法とパラメータ最適化アルゴリズムを解説する技術ドキュメントです。
「エンジンの強さの差をどう定量化し、どうパラメータを最適化するか」を軸に、
理論的背景から実装の詳細まで積み上げる構成になっています。

## なぜ内部実装を理解するべきか

ShogiArena を使うだけなら、SPRT や SPSA の内部を知る必要はありません。
しかし、以下のようなケースでは、統計理論と最適化アルゴリズムのレベルまで理解していることが大きな武器になります。

- **SPRT のパラメータを適切に設定したい**: elo0/elo1、α/β の選び方は検定の感度と所要ゲーム数に直結します。理論を知らずに設定すると、何千局も無駄に対局するか、誤った結論を導くことになります
- **SPSA でエンジンのパラメータを効率的にチューニングしたい**: ゲインスケジュール（a_k, c_k）の設計は収束速度と安定性のトレードオフであり、問題の性質に応じた調整が必要です
- **検定結果を正しく解釈したい**: LLR の値、信頼区間、五項分布の意味を理解していないと、統計的に有意でない結果を「改善」と判断してしまう危険があります
- **ShogiArena に貢献したい**: 統計モジュールの設計意図とアルゴリズムの不変条件を理解していないと、バグを生む変更をしてしまいます

## 想定読者

- 大学レベルの確率・統計の基礎知識がある
- 仮説検定（帰無仮説・対立仮説・有意水準）の概念は理解している
- 将棋エンジンの開発・評価に携わっている、または興味がある
- 最適化アルゴリズムの基本概念（勾配降下法など）を知っている

## 全体の流れ

```text
elo ─────────────────────────────→ sprt ──→ spsa → variance-reduction
 レーティング                       仮説検定   最適化   分散削減
 ├── bayeselo（引き分けモデル）       ├── llr       ├── noise-and-higher-order
 └── nelo（正規化Elo）               ├── gsprt     └── ltc-regression
                                    └── pentanomial
```

1. **[Elo レーティング](./elo/index.md)**: エンジンの強さを数値化する基礎理論
   - **[BayesElo と引き分けモデル](./elo/bayeselo.md)**: 引き分け率を明示的にモデル化する Elo の拡張と LOS
   - **[正規化 Elo（nElo）](./elo/nelo.md)**: 引き分け率に依存しない強さの指標
2. **[SPRT（逐次確率比検定）](./sprt/index.md)**: エンジン間の強さの差を統計的に判定
   - **[対数尤度比（LLR）](./sprt/llr.md)**: SPRT の核心となる検定統計量
   - **[GSPRT（一般化 SPRT）](./sprt/gsprt.md)**: MLE ベースの正確な LLR 計算とオーバーシュート補正
   - **[五項分布モデル](./sprt/pentanomial.md)**: ペアゲームによる高精度な分析
3. **[SPSA（同時摂動確率近似法）](./spsa/index.md)**: エンジンパラメータの自動最適化
   - **[勾配推定と摂動](./spsa/gradient.md)**: Rademacher 摂動による効率的な勾配推定
   - **[ゲインスケジュール](./spsa/gain-schedule.md)**: 収束を制御する減衰系列の設計
   - **[ノイズと高次手法の限界](./spsa/noise-and-higher-order.md)**: 二次手法が使えない理由と実践知
   - **[LTC 回帰テスト](./spsa/ltc-regression.md)**: チューニング結果の長時間検証
4. **[分散削減テクニック](./variance-reduction/index.md)**: 少ないゲーム数で高精度な推定を得る手法
5. **[用語集](./glossary.md)**: 本ドキュメントで使用される専門用語のリファレンス
6. **[テストフレームワーク概説](./testing-frameworks.md)**: OpenBench・Fishtest・Cutechess の解説と ShogiArena の位置付け

## 依存関係

```text
elo ────────────────────────────────┐
  勝率モデル → レーティング → 信頼区間   │
  ├── bayeselo（引き分けモデル, LOS）   │
  └── nelo（正規化Elo）                │
                                     ▼
sprt ────────────────────────────────┐
  仮説設定 → LLR計算 → 逐次判定        │
  ├── gsprt（MLE, オーバーシュート）    │
  └── pentanomial（五項分布）           │
                                     ▼
spsa ────────────────────────────────┐
  摂動 → 勾配推定 → パラメータ更新      │
  └── LTC回帰テスト ◄── (sprt)        │
                                     ▼
variance-reduction ◄── (elo, sprt, spsa)
  CRN → バッチ処理 → 分散削減
```

SPSA の LTC 回帰テストでは SPRT を内部的に使用するため、
SPRT を先に理解してから SPSA に進むことを推奨します。

## 推奨読了パス

読者の目的に応じて、以下のパスを推奨します。

**エンジン評価者（対局結果を正しく読みたい）**:
elo → elo/bayeselo → sprt/index → sprt/llr
レーティングの意味、LOS の読み方、SPRT の判定基準を理解します。
不明な用語は [用語集](./glossary.md) で確認できます。

**エンジン開発者（パラメータチューニングをしたい）**:
elo → elo/nelo → sprt/index → spsa（全ページ）→ variance-reduction
正規化 Elo と SPSA の設定を適切に行い、効率的なチューニングを実現します。

**統計に詳しい人（理論的背景を深掘りしたい）**:
全章を依存関係の順に通読してください。特に sprt/gsprt は
MLE ベースの LLR 計算とオーバーシュート補正の数学的詳細を、
elo/nelo は引き分け率非依存性の理論的根拠を解説しています。

**ShogiArena 開発者（コードに変更を加えたい）**:
全章を通読した上で、各章末の「実装リファレンス」でソースコードの対応箇所を確認してください。
[テストフレームワーク概説](./testing-frameworks.md) で、参考にした外部フレームワークとの関係も把握しておくと有益です。
